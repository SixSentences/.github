SixSentences connects literature discovery, evidence collection, research-data
analysis, surveys and interviews, scientific visuals, and manuscript work. The
goal is not to hide the research process behind automation, but to keep inputs,
transformations, provenance, and human decisions visible.

## Open source

The [`sixsentences`](https://github.com/SixSentences/sixsentences) repository
contains two complementary surfaces:

- a typed Python library and CLI for auditable literature, evidence, reporting,
  and bounded research-data workflows; and
- a sanitized Next.js client for the wider research workspace, including
  search, library, projects, data, figures, surveys, interviews, knowledge,
  brainstorming, and writing.

The current alpha is intentionally honest about its boundary: the web client
requires a separately supplied compatible API. The marketing site, hosted SaaS
backend, billing, operator tooling, provider accounts, production data, browser
extension, and macOS companion are not part of this source release.

## Start or contribute

- [Read the project overview](https://github.com/SixSentences/sixsentences#readme)
- [Install the latest prerelease](https://github.com/SixSentences/sixsentences/releases)
- [Explore concrete next steps](https://github.com/SixSentences/sixsentences/issues)
- [Review the contribution guide](https://github.com/SixSentences/sixsentences/blob/main/CONTRIBUTING.md)
- [Report a vulnerability privately](https://github.com/SixSentences/sixsentences/security)

Contributions are accepted under Apache-2.0 with per-commit DCO sign-off. The
SixSentences name, logo, and visual identity remain protected marks; the source
repository documents the exact code, dependency, and trademark boundaries.

## Hosted workspace

[sixsentences.com](https://sixsentences.com) and
[app.sixsentences.com](https://app.sixsentences.com) are operated separately.
They provide the integrated hosted deployment and may include capabilities that
are not available in the community source tree.
