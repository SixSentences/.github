# SixSentences

SixSentences builds transparent, audit-friendly tools for literature search and
evidence-synthesis workflows.

## Open source

Our first public project is
[SixSentences Engine](https://github.com/SixSentences/sixsentences): a typed
Python library and command-line tool for Boolean query translation, local
scholarly-corpus search, ranking, deduplication, coverage estimation, screening
utilities, and PRISMA reporting.

The engine is early-alpha software. It supports research workflows; it does not
guarantee search completeness, produce a systematic review by itself, or replace
expert judgment.

## Hosted product

The hosted service at [sixsentences.com](https://sixsentences.com) is operated
separately. Its website, accounts, billing, provider integrations, customer
data, and production infrastructure are not part of the public engine
repository.

Contributions are welcome through focused issues and pull requests. Please use
each repository's private vulnerability-reporting flow for security concerns.
